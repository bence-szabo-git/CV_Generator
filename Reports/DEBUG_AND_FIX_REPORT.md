# Typst CV Template — Two-Column Layout Fix

## Problem Diagnosed

The template was failing to render a two-column layout. Every approach attempted produced single-column output despite using `#grid()` with explicit column widths.

## Root Cause

The culprit was `#block(width: ...)` wrappers around grid cell content. When large content blocks were wrapped with explicit widths, Typst's grid layout algorithm couldn't properly distribute columns side-by-side. The `block()` constraint was overriding the grid's column sizing.

## Solution Applied

**Removed all `#block()` wrappers from grid cells** and used pure content blocks (`[]`) instead. This allows the grid layout engine to work correctly with the explicit column widths.

### Key Changes:

1. **Helper Functions**: Changed from `#block(width: 100%)` to bare `[]` returns
   ```typst
   // BEFORE (broken):
   #let section-heading(title) = block(width: 100%)[...]
   
   // AFTER (working):
   #let section-heading(title) = [...]
   ```

2. **Two-Column Grid**: Kept explicit widths but removed block wrappers on cell content
   ```typst
   #grid(
     columns: (11.16cm, 0.54cm, 6.3cm),
     gutter: 0pt,
     
     // BEFORE (broken):
     block(width: 11.16cm)[LEFT COLUMN],
     
     // AFTER (working):
     [LEFT COLUMN],
   )
   ```

## Verification

Compiled successfully with **Typst 0.14.2** on the devcontainer.

**PDF Position Analysis** (via pdfplumber):
- "Professional Experience" heading: x=42.5pt (left column)
- "Summary" heading: x=374.2pt (right column) at **identical Y=194.8pt**
- Horizontal distance: ~330pt ≈ **11.6cm (matches intended 11.16cm left column)**

**Conclusion**: ✅ Two-column layout is rendering correctly side-by-side.

## Template Structure

### Header (Full-Width)
- Name: 28pt, bold, navy
- Contact: 2×2 grid (email + phone, LinkedIn + nationality) with unicode icons
- Photo: 3.5cm × 3.5cm box (right-aligned)
- Divider line

### Body (Two-Column via `#grid()`)

**Left Column (11.16cm):**
- Professional Experience
  - Company name (bold) + description (italic) + logo (1cm, left)
  - Multiple roles per company, each with:
    - Dates + location (narrow strip, 2.8cm)
    - Role name (bold, ● bullet, navy color)
    - Bullet points
- Extracurricular Experience
  - Dates + location (narrow strip, 2.8cm)
  - Role name (bold, teal)
  - Event name (bold)
  - Section description (italic)
  - Bullet points

**Gap (0.54cm):** Spacer

**Right Column (6.3cm):**
- Summary (plain text, 9.5pt)
- Education
  - Degree (bold) + University + Location + Dates
  - Institution logo (1.1cm, right-aligned) if available
- Languages
  - Name (bold) : Level (plain), one per line
- Skills
  - Category (bold) on its own line
  - Comma-separated skills below
- Awards & Scholarships (bulleted list, if present)

### Colors
- Navy `#1a3a5c`: Section headings, role bullets (● marker)
- Teal `#1a7a7a`: Extracurricular role names, section divider lines

## Logo Rendering Guards

**Professional Experience Companies:**
```typst
#if job.keys().contains("logo_path") and job.logo_path != "" [
  #image(job.logo_path, width: 1cm)
]
```

**Education Institutions:**
```typst
#if logo != "" [
  #image(logo, width: 1.1cm)
]
```

Both guards safely skip rendering when paths are empty, preventing Typst errors.

## Technical Notes for Future Work

1. **Typst Version Compatibility**
   - Tested with: Typst 0.14.2
   - `#grid()` with explicit `columns: (width1, width2, ...)` works correctly
   - `#block(width: Npx)` wrappers inside grid cells should be avoided
   - `#columns()` (newspaper-style) wasn't suitable for this use case

2. **PDF Text Extraction Caveat**
   - Standard PDF text extraction (pypdf) doesn't preserve columnar layout
   - Use pdfplumber with `extract_words()` to get x,y coordinates for verification
   - Visual layout is correct even when text extraction appears linear

3. **Potential Enhancements**
   - True circular photo cropping (may require Typst 0.12+)
   - Dynamic column height balancing
   - Additional visual tweaks to spacing/padding
